# Bank Pet (Java Middle Interview Demo)

Полноценный демо-банк на Spring Boot:
- свой банк + свои карты/счета клиентов;
- кошелёк цифрового рубля;
- AI Spending Guardian + LLM-анализ риска;
- NFC-платежи под капотом (без отдельного NFC-экрана);
- синхронизация истории из других банков;
- REST API + Web UI (Thymeleaf).

## Что изменили сейчас
- Исправлен фон UI: это снова один плавный градиент (не 3 полосы).
- Добавлена верхняя строка с быстрым отображением:
  - счёта,
  - карты,
  - блока цифрового рубля.
- Карты теперь в модели банка хранятся как **собственные карты** с 11-значным PAN формата demo.
- Хранение PAN сделано в зашифрованном виде (AES/GCM), в интерфейс выводится расшифрованное значение для владельца.
- Карточный мини-блок стилизован в желто-фиолетовый градиент.

## Безопасность и шифрование
- `CardDataProtectionService` шифрует PAN (AES/GCM/NoPadding).
- В БД хранится `encryptedPan`, а не номер в открытом виде.
- В `application.yml` добавлен ключ `app.security.card-encryption-key` (для демо).
- Для production:
  - хранить ключи в Secret Manager/KMS;
  - ротация ключей;
  - токенизация карт;
  - PCI DSS-подобные контроли и аудит.

## Насколько реально обернуть траты по NFC и картам банков?
Реально только через официальную платёжную инфраструктуру:
1. токенизация карт (network/device token),
2. эквайринг/процессинг,
3. антифрод и комплаенс,
4. партнерские соглашения с банками/платформами.

То есть архитектурно возможно, но не как «универсальная обертка на любой банк без интеграций».

## Насколько реально подключение цифрового рубля?
Реально при наличии официального API/регламента платформы ЦБ:
- сертифицированный контур,
- KYC/AML,
- события статусов и сверка операций,
- юридическое подключение и доступы sandbox/prod.

## Публикация в Google Play (проверяем в деле)
Рекомендуемый путь: **TWA (Trusted Web Activity)**.

1. Развернуть сайт по HTTPS (Render/VPS).
2. Добавить `assetlinks.json` на домен.
3. Установить Bubblewrap:
   ```bash
   npm i -g @bubblewrap/cli
   ```
4. Инициализировать Android-обертку:
   ```bash
   bubblewrap init --manifest https://<your-domain>/manifest.webmanifest
   ```
5. Собрать `.aab`:
   ```bash
   bubblewrap build
   ```
6. Подписать `.aab` релизным ключом.
7. Загрузить в Google Play Console (Internal testing -> Production).

## Почему Spring может не стартовать
Если видишь `Non-resolvable parent POM ... 403 Forbidden`, это проблема доступа к Maven Central, не логики приложения.
