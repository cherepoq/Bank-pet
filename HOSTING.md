# Домен и hosting для RentFlow

Цены меняются часто. Ниже приведён бюджетный ориентир, а не оферта; перед оплатой проверьте итоговую цену, НДС, стоимость продления и резервных копий на официальной странице поставщика.

## Рекомендуемая стартовая конфигурация

- 2–4 vCPU, 4 ГБ RAM, 50–80 ГБ NVMe;
- Ubuntu 24.04;
- публичный статический IPv4;
- backup/snapshot минимум раз в сутки;
- отдельное S3-compatible хранилище для production-медиа.

Ориентир бюджета российского VPS такого размера: **900–2 500 ₽/месяц**. Резервные копии, дополнительный диск, исходящий трафик и object storage оплачиваются отдельно. Для первых 20–50 тестировщиков достаточно 2 vCPU/4 ГБ; для параллельного FFmpeg лучше 4 vCPU/8 ГБ.

## Где смотреть

1. **Timeweb Cloud** — удобный кабинет и быстрый старт: <https://timeweb.cloud/services/vds>.
2. **Selectel** — больше production-инструментов, managed services и вариантов размещения: <https://selectel.ru/services/cloud/servers/>.
3. **Beget VPS** — простой бюджетный VPS: <https://beget.com/ru/vps>.

Для первого Internal testing практичный выбор — Timeweb Cloud или Beget. Для production с managed PostgreSQL, S3 и требованиями к инфраструктуре стоит сравнить Selectel с выбранным первым поставщиком.

## Домен

Домен можно купить у регистратора REG.RU, RU-CENTER, Timeweb или Beget. Для российского проекта удобно использовать `.ru`; для международного бренда — `.app` или `.com`.

Ориентиры без учёта акций:

- `.ru`: примерно **300–1 200 ₽ за первый год**, продление часто дороже;
- `.com`: примерно **1 200–2 500 ₽ в год**;
- `.app`: примерно **1 500–3 500 ₽ в год**, HTTPS обязателен по правилам зоны.

Проверяйте отдельно цену **продления**, WHOIS privacy, DNSSEC и возможность переноса домена. Домен регистрируйте на владельца продукта, а не на подрядчика.

## Порядок покупки и запуска

1. Проверить свободное имя у 2–3 регистраторов и сравнить продление.
2. Зарегистрировать домен с корректными данными владельца и включить 2FA.
3. Купить VPS, добавить SSH-ключ и отключить password login.
4. Создать DNS `A` для `app` на IPv4 VPS.
5. Скопировать `.env.production.example` в `.env` и заменить все `REPLACE_*`.
6. Запустить `docker compose --profile edge up -d --build`.
7. Выполнить `./scripts/domain_check.sh app.example.ru`.
8. Только после успешной проверки создавать TWA release для этого домена.
