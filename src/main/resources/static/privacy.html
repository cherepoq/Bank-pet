Политика конфиденциальности RentFlow

Черновик для тестового выпуска · обновлено 20 августа 2026

Какие данные обрабатываются

RentFlow обрабатывает сведения об объектах аренды, сроках, ручных записях об оплате, документах, чеках и видео, которые пользователь загружает самостоятельно.

Хранение и защита

Файлы шифруются до записи в хранилище. Передача на сервер выполняется по HTTPS. Доступ должен предоставляться только авторизованным участникам аренды.

Платежи

Текущая версия не переводит деньги и не хранит данные банковских карт. Записи об оплате создаются пользователями вручную.

Удаление

Пользователь может запросить удаление аккаунта и связанных данных через службу поддержки. До публичного релиза здесь должны быть указаны юридическое лицо, контактный email, сроки хранения и применимая юрисдикция.
