Удаление аккаунта RentFlow

Как отправить запрос

До появления удаления внутри приложения отправьте запрос с email, использованного при регистрации, на support@REPLACE_WITH_DOMAIN с темой «Удаление аккаунта».

После проверки владения аккаунтом профиль, договоры, ручные записи и связанные файлы будут удалены в срок, указанный в итоговой политике хранения.

Перед production-релизом замените контакт и добавьте автоматическое удаление из профиля. Эта страница предназначена для Internal testing.
