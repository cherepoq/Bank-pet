# Как открыть и проверить интерфейс RentFlow

## Вариант 1 — самый быстрый, без Java и Docker

Из корня проекта выполните:

```bash
./scripts/static_preview.sh
```

В терминале появится адрес `http://localhost:4173`. Откройте его в Chrome или Edge. Не открывайте `dashboard.html` двойным кликом: при URL вида `file:///...` service worker, manifest и часть модулей браузера работать не будут.

Остановить preview: `Ctrl+C`.

## Проверка в размере телефона

1. Откройте preview в Chrome.
2. Нажмите `F12`.
3. Нажмите иконку телефона **Toggle device toolbar** или `Ctrl+Shift+M`.
4. Выберите `iPhone 14 Pro`, `Pixel 7` или ширину `390 px`.
5. Масштаб DevTools установите в `100%` и обновите страницу.

Интерфейс mobile-first, но на широком экране намеренно показывается в аккуратном контейнере приложения, а не растягивается на весь монитор.

## Вариант 2 — посмотреть с настоящего телефона в локальной сети

```bash
PORT=4173 ./scripts/static_preview.sh
hostname -I
```

Телефон и компьютер должны быть в одной Wi-Fi сети. На телефоне откройте `http://<IP-компьютера>:4173`. Firewall должен разрешать входящее соединение на порт 4173.

## Вариант 3 — публичная ссылка GitHub Pages

1. Слейте изменения в `main`.
2. Откройте GitHub → **Actions** → **Deploy RentFlow preview to GitHub Pages**.
3. Дождитесь зелёного статуса или нажмите **Run workflow** и выберите нужную ветку.
4. Откройте ссылку deployment.
5. Проверьте `<pages-url>/revision.txt`: там должен быть SHA нужного коммита.

Если раньше открывалась старая версия, обновите страницу два раза. Новый service worker удаляет старые кэши автоматически. В крайнем случае: DevTools → Application → Storage → **Clear site data**.

## Вариант 4 — frontend вместе с backend

```bash
./scripts/local_preview.sh
```

После запуска откройте `http://localhost:8080/app`.

## Что проверить вручную

- нижняя навигация на всех пяти вкладках;
- переключение арендодатель/арендатор;
- круговой таймер и ручной учёт оплаты;
- добавление объекта;
- загрузка, поиск и скачивание файла;
- загрузка видео;
- отображение при ширине 320, 390, 430 и 760 px;
- отсутствие горизонтального скролла;
- крупный текст и системную тёмную тему не должны ломать layout.
